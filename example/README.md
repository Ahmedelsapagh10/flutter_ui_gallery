# Nova Surfaces — Interactive Component Gallery

The interactive showcase application for `flutter_ui_gallery` (Nova Surfaces).

## Features

- **All 12 Presets Accessible**: Live interactive previews for every Bottom Sheet, Dialog, Toast, and AppBar design.
- **Responsive Device Previews**: Toggle between Phone (390dp), Tablet (768dp), and Desktop (1200dp) device frames.
- **Interactive Playground**:
  - Live title and message text fields that update the preview in real-time.
  - Light and Dark appearance switching.
  - Arabic (RTL) and English (LTR) language switching with localized sample content.
  - Reduced-motion preview toggle.
  - Accent color picker with preset palette and custom HEX input.
- **Copyable 1–3 Line Recipes**: Copy ready-to-use Flutter snippets directly from the showcase.

## Getting Started

Run the showcase locally:

```bash
cd example
flutter run -d chrome  # or macos, ios, android
```
